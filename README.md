## ⚡ Overview

**lazyssh** is a terminal-based UI (TUI) and CLI tool designed to make working with SSH hosts, configurations, keys, and tunnels as effortless and intuitive as [lazygit](https://github.com/jesseduffield/lazygit) did for Git.

Instead of memorizing IP addresses, digging through hundreds of lines in `~/.ssh/config`, or writing repetitive terminal commands, **lazyssh** gives you a single, responsive keyboard-driven dashboard to search, inspect, connect, manage port forwards, and monitor remote host latency.
